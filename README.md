# Resume

Resume ritten in Markdown and rendered to HTML and PDF with Jekyll and CSS.

Forked from [markdown-cv](https://github.com/elipapa/markdown-cv) by Eliseo Papa ([GitHub](https://github.com/elipapa) / [website](https://elipapa.github.io)). MIT License.

## Distribution

Published with GitHub Pages from the `master` branch at [naelah.github.io](https://naelah.github.io). Push to `master` and the site updates.

## Build

1. [Install Jekyll](https://jekyllrb.com/docs/installation/).
2. Run `jekyll serve`.
3. Open http://localhost:4000 and edit `index.md`. The page rebuilds as you save.
4. Use **Download PDF**, or press <kbd>⌘</kbd> + <kbd>P</kbd>, and choose Save as PDF. Print CSS sets the page margins.
